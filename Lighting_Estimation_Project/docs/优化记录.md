# 优化记录

本轮使用10张真实室内HDR：8个训练场景、1个验证场景、1个测试场景。正式研究数据集尚未获取。新旧验证和测试目标逐像素相同，旧权重和失败记录均保留。

压缩倍率从16改为8，token数由32增至128；增加残差重建、多频位置编码、亮源与边缘损失，以及照片条件辅助token监督。生成仍按因果顺序执行，辅助分支不读取未来目标。

| 同一测试场景的四个视角 | log-HDR RMSE | 漫反射误差 | 相对能量误差 |
|---|---:|---:|---:|
| 旧版纯AR | 0.502152 | 0.449885 | 0.516492 |
| 新版纯AR | 0.500791 | 0.424018 | 0.465805 |
| 新版加可见区域约束 | 0.480565 | 0.372397 | 0.347434 |

tokenizer重建误差从0.443893降至0.280449。这项改善不能当作照片预测能力提升。纯AR完整生成误差基本未改善。

输入打乱检查：选中模型在验证场景生成的token完全不变，正常与打乱输入的log-HDR误差均为0.351117。结构梯度连通性检查通过，但训练后的有效条件依赖仍未建立。

可见区域约束属于明确的几何投影步骤：将照片映射回已知视野，尺度从原始预测估计，不读取真值；饱和像素只提供下界，未观测方向保持原AR输出。它改善输入一致性，但存在色差和局部嵌入感，不能掩盖神经模型的问题。

本轮没有达到实际光照恢复的可用精度。需要扩大训练覆盖并解决条件建模，不支持论文性能或创新结论。
