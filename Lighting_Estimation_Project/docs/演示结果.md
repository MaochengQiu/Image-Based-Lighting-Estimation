# 2026-11-10 工程演示记录

使用已有 D:/conda/envs/lighting 环境，PyTorch 2.8.0+cpu。CUDA安装下载失败，没有完成GPU训练。

数据为Poly Haven的3张CC0真实室内HDR，每个集合仅1个场景，共生成20个配对样本（12训练、4验证、4测试）。独立场景数量非常小，结果不支持泛化或论文性能结论。

执行了连续自编码预热100轮、训练集k-means初始化、VQ训练40轮、AR训练30轮。按验证集log-HDR RMSE选择checkpoint，测试集仅用于记录结果，未按测试结果选择checkpoint。

对照运行全部保留：

- runs/demo_20261110：随机码本版本，单码字坍塌。
- runs/demo_20261110_kmeans：仅初始化版本，仍有严重码本退化。
- runs/demo_20261110_warmup：预热后初始化，完成训练、评估与独立单图预测。

最终版本测试集tokenizer使用16个码字，AR生成使用9个码字。tokenizer log-HDR RMSE为0.443893，AR为0.502152；这些是该极小演示的数据，不适用于正式排名。

已检查：VQ和图像编码器梯度、未来token隔离、图像条件连通性、从BOS独立生成、checkpoint加载、HDR保存后读回以及对比图。梯度和条件连通性检查不等于证明已训练模型有效利用条件。

预测仍明显模糊，亮源位置和高亮强度恢复不足。码本非坍塌不代表光照准确；当前只完成工程闭环。下一阶段需要扩大训练场景、验证tokenizer重建质量、检查已训练模型的条件敏感性，并建立正式基线。
