# 自回归受控实验记录

本轮固定现有8个训练场景、1个验证场景、1个测试场景和tokenizer。各组使用相同种子及100轮训练，依次验证可见区域优先、10%前序token随机替换、预训练ResNet-18。预训练组冻结骨干，将输入缩放至224像素并缓存冻结特征。

## 检查结果

同一真实前缀下，完整训练接口与逐步生成接口的logits最大差异在约3e-6以内。检查的前缀长度为1、2、8、16、32、64、128。可见优先的目标排列、因果性及生成后的逆排列检查通过。排序按token中心方向近似判断可见性。

单张训练照片50步后完整生成准确率达到100%，解码结果达到该照片的tokenizer重建误差。

| 配置 | 最佳验证log-HDR RMSE | 观察 |
|---|---:|---|
| 原基线 | 0.351117 | 所选模型对同一验证场景的不同朝向输出相同token |
| 可见区域优先 | 0.384317 | 验证误差更高，首token仍常出错 |
| 前序token扰动 | 0.355126 | 未观察到验证误差改善 |
| 预训练ResNet-18 | 0.351365 | 验证误差接近基线，照片响应明显增强 |

预训练模型最后一轮在全部96个训练配对上完整生成token准确率为100%，96张全部序列正确。原基线最后一轮在相同96张上准确率为38.3545%，仅8张整序列正确。训练样本由8个原始全景的旋转和曝光变化构成，独立场景数量仍然是8。

最后一轮训练拟合与最佳验证权重分别保留。96张训练拟合通过的权重不是最佳验证权重。预训练组最佳验证模型交换跨场景输入后约86%的生成token改变。

选择时先要求生成结果对输入变化有响应，再最小化验证log-HDR误差。该规则依据此前方案中的条件有效性要求加入。它只检查响应，不能保证响应正确。最终选中的预训练组在测试场景四个视角上的log-HDR RMSE为0.514395，原基线为0.500791，本轮未改善陌生场景预测效果。

## 产物与复现

入口为 scripts/run_ar_ablation.py，运行环境为 D:/conda/envs/lighting/python.exe。图表由 scripts/render_ar_ablation.py 生成。

数据和tokenizer指纹、模型指纹、配置、日志、最佳与最后一轮权重、逐样本预览都在 runs/ar_controlled/。报告为 runs/ar_controlled/index.html。full_train_comparison.json 保存全部96张的同口径检查。

预训练训练拟合权重为 runs/ar_controlled/pretrained/last.pt。验证选择的权重为同目录 best.pt。两者使用 runs/demo_optimized_v1/tokenizer/best.pt。

本次仍在CPU执行。TorchVision 0.23.0+cpu与官方ResNet-18权重已安装。完整Laval标定集尚未获取，本次访问下载入口仍然超时。数据扩展和多房间验证尚待完成。

目前的证据支持预训练视觉特征有助于训练集条件映射和完整生成。八场景下的泛化仍不足，三组单种子结果也不足以得出普遍方法结论。
